EventPulse Ecosystem

Next-Gen Intelligent Event Registration & Ticketing System
Built with PHP 8.3, MySQL 8.0, Bootstrap 5.3, HTML5 Canvas 2D, and Web Audio API

Executive Summary

EventPulse is a full-featured, production-ready web platform created to modernize event ticketing and venue admission. By replacing flat ticket dropdowns and static barcodes with an interactive SVG stadium layout, real-time stage perspective simulations, dynamic anti-scalping TOTP security, AI conference itinerary synthesis, and team squad perks, EventPulse sets a new standard for modern event management software.

The 5 Core System Novelties

Novelty 1: Interactive SVG Seating Map & Real-Time Stage Perspective

Physical venue spatial computing & acoustic simulation.

Attendees choose their exact seats from a tiered 96-node stadium grid across VIP Sovereign, Premium Gold, and Standard tiers. A real-time Canvas 2D viewport calculates stage distance (6m to 26m), lateral angle offset (-36° to +36°), and an acoustic clarity score. Concurrency is preserved via MySQL row-level locks and 5-minute checkout holds.

Novelty 2: Anti-Scalp Rotating TOTP Pass & Audio Gatekeeper

Cryptographic pass watermarking and instant camera admission.

Screenshots and duplicate reselling are rendered useless by a rotating 8-character token recomputed every 30 seconds using HMAC-SHA256. At the gate, organizers use their smartphone or laptop camera with the built-in optical scanner. Web Audio API produces two-tone chord chimes for valid admissions and low saw-wave alert buzzes on duplicate check-in attempts.

Novelty 3: AI Event Concierge & Session Matchmaker

Algorithmic schedule synthesis and peer cohort matching.

Attendees input their professional role (Engineer, Founder, Designer) and conference targets. The concierge synthesizes a conflict-free chronological agenda, pairs them with relevant networking cohorts, and enables 1-click export of an RFC-compliant .ics calendar file to Google Calendar, Apple iCal, and Outlook.

Novelty 4: Squad RSVP & Group Perks Engine

Viral team referral codes with automated volume tier discounts.

Squad leaders generate shareable team codes (e.g. SQ-TECH-4912) and invite colleagues. Applying the squad code at checkout immediately grants a 15% to 20% discount across all passes and generates coordinated team delegation passes for the event.

Novelty 5: Dynamic Demand Surge & Verified Carbon Offset Eco-Badge

Telemetry demand velocity and verified tree-planting badges.

Live telemetry tracks hourly ticket velocity and triggers early-bird countdown triggers. An optional $5 contribution funds 2 certified native trees, removes 50 kg of CO₂, and attaches a verifiable "Eco-Guardian" badge and certificate hash to the pass.

System Architecture & Data Schema

The database schema is fully normalized into 11 relational tables under eventpulse_db:

Table Name Primary Key Role & Responsibility
users id Authentication, bcrypt hashes, role-based access (admin, organizer, attendee).
events id Event profile, category, venue name, address, dates, seating configuration.
ticket_tiers id Pricing tiers (VIP, Premium, Standard), capacity, and perks JSON.
seats id Individual seat coordinates, rows, status (available, reserved, booked).
bookings id Order records, references, financial subtotals, discounts, net amount.
ticket_items id Issued passes, attendee info, cryptographic SHA-256 hash, check-in status.
squads id Team delegation records, referral codes, target sizes, member progress.
carbon_offsets id Environmental impact records: trees funded, kg CO₂ offset, certificate hashes.

Quality Assurance & Security

  • Password Protection: Hashed using PHP’s password_hash() with BCrypt (Work Factor 10).
  • SQL Injection Immunity: 100% of queries use PDO Prepared Statements with strictly bound parameters.
  • Cross-Site Scripting (XSS): Output escaping on all user content using htmlspecialchars().
  • Cross-Site Request Forgery (CSRF): Cryptographically signed session tokens on state mutations.
  • Functional Test Verification: All endpoints tested via HTTP POST; optical camera QR scanning confirmed with live audio feedback.
